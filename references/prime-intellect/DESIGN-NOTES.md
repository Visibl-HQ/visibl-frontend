## What to borrow (maturity signals)

| Signal | Prime Intellect | Visibl application |
|--------|-----------------|-------------------|
| Typography | Geist + mono labels (`FIG.01`, metadata) | Keep editorial serif for headlines; Geist + Geist Mono for UI/chat |
| Color | Near-black canvas, warm gray panels, one confident accent | Graphite workspace, cyan brand accent, no rainbow gradients |
| Chat | Clean thread, floating composer, restrained bubbles | Independent scroll column, mono role labels, panel-style assistant replies |
| Layout | Technical grid, numbered sections, dense but legible | FIG labels on landing, grid backdrop in chat |
| Motion | Subtle, functional | Streaming cursor, soft panel reveal — no decorative loops in workspace |

## Chat UI patterns

- **Assistant**: full-width panel, left accent rail, mono label row (`VISIBL · INTAKE`)
- **User**: compact right-aligned capsule, asymmetric radius (tail corner)
- **Composer**: floating docked card, border + blur, integrated send
- **Background**: faint orthogonal grid, not decorative blobs
